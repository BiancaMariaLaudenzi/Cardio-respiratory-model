CARDIO-RESPIRATORY MODEL - LIST OF CHANGES
Reference version: https://github.com/BiancaMariaLaudenzi/Cardio-respiratory-model (version v1.1.0)

======================================================================
1. INPUT FILE inputData.dat
======================================================================

1.1 Added a second order numerical method, numerical method numbering changed
    Before: method = 0 Euler, 1 Runge-Kutta 4.
    Now:    method = 0 Euler, 1 Heun (new), 2 Runge-Kutta 4.

1.2 Automatic reparametrization when control mechanisms are switched off
    If doControlCardio = 0 and inputData.dat defines commonParamsNoControl,
    that file is used instead of commonParams.
      commonParamsNoControl = <path>/commonParams_noControl.dat
    If the key is missing, commonParams is used as before.

======================================================================
2. PARAMETER FILES
======================================================================

2.1 Reparametrization of cardiovascular.dat
    - trRA and trLA are no longer inputs. They are computed as
        trRA = tcRA + TcpRA,  trLA = tcLA + TcpLA   (rounded to 1e-3)
      With the default values the result is unchanged (0.80 + 0.17 = 0.97).
    - New valve parameters, in section [valve]:
        MstTV, MstPV, MstMV, MstAV   (default 1)
        MrgTV, MrgPV, MrgMV, MrgAV   (default 1e-5)
      They allow the simulation of valve stenosis/regurgitation:
        Amax = A * Mst,  Amin = A * Mrg
    - Changed values for pv-loops parametrization:
        rpp   0.0894 -> 0.045
        Rpp   0.0001 -> 0.045
        Rp    0.001  -> 0.01
        eARA  0.06   -> 0.11
        eBRA  0.04   -> 0.07
        eALA  0.07   -> 0.2
        eBLA  0.05   -> 0.135
        kelv  0.014  -> 0.015
        kerv  0.011  -> 0.013

2.2 New file commonParams_noControl.dat
    Same structure as commonParams.dat. It contains the values of the controlled
    variables (resistances, unstressed volumes, maximum elastances) averaged over
    the last 60 s of a 2000 s simulation with all controls active, and
    T0 = 0.88 s (HR = 68 bpm). It is used when doControlCardio = 0, so that a
    simulation without cardiovascular control starts from the same state
    reached by the controlled baseline.

2.3 commonParams.dat
    - Changed value for pv-loops parametrization:
        emaxrv0  1.412 -> 1.1296

2.4 Compatibility with v1.1.0
    Parameter files of version v1.1.0 cannot be used with this version: the
    sections of commonParams.dat were renamed.
    A key that is not found is replaced by its default value coded in the .cc
    without any error message.

======================================================================
3. MODEL AND NUMERICAL CHANGES
======================================================================

3.1 Arterial O2/CO2 content (transport.cc)
    The mixing of pulmonary capillary blood and shunt blood (cao2, caco2) now uses
    the pulmonary (qpp) and shunt (qps) flows filtered by a first-order low-pass
    filter (time constant 0.75 s), updated once per time step
    (new function gasTransport::updateFlowFilter). Before, the instantaneous
    pulsatile flows were used.

3.2 Time integration and simulation control (closedloop.cc)
    - New method: Heun (explicit trapezoidal rule, 2nd order), method = 1.
    - NaN check: if a NaN appears in the state vector, the simulation stops and
      nan_detected.txt is written in the results folder.
    - Convergence check: from nextConvCheck on, every windowConv seconds the mean
      over the last window is compared with the mean over the previous window for
      systemic arterial pressure, central venous pressure, aortic valve flow, heart
      period (if the cardiovascular control is active), PaO2 and PaCO2 (if gas
      transport is active). If all relative changes are below tolConv, the
      simulation stops and convergence_report.txt is written. The windows are filled
      with the sampled values, so sampling must cover the last two windows
      (tSampleIni, dtSample).

======================================================================
4. OUTPUT
======================================================================

- GAS_AlveoliLungsAlg.txt: new last column [14] sao2 (arterial O2 saturation).
  The previous columns are unchanged.
- New files, written only when the corresponding event occurs:
  convergence_report.txt, nan_detected.txt.
